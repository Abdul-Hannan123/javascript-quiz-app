## 🧠 Quiz App

A simple and interactive Quiz App built using HTML, CSS, and JavaScript. Users can answer multiple-choice questions, receive instant feedback for each answer, and see their final score when the quiz is completed.

---

## 🚀 Features

- 🧠 Multiple-choice quiz questions
- ✅ Select the correct answer
- ❌ Automatically identifies incorrect answers
- 🟢 Correct answer is highlighted in green
- 🔴 Wrong answer is highlighted in red
- 🔒 Once an answer is selected, it cannot be changed or selected again
- ➡️ Next button to move through the questions
- 📊 Displays the final score after completing the quiz
- 📱 Responsive and clean user interface
- ⚡ Built using vanilla JavaScript without external libraries

---

## 🛠️ Technologies Used

- HTML5 – Structure of the quiz
- CSS3 – Styling and responsive layout
- JavaScript – Quiz logic, answer checking, question navigation, and score calculation
