## 🧠 Quiz App

A simple and interactive Quiz App built with using HTML, CSS, and JavaScript. Users can answer multiple-choice questions, receive instant feedback for each answer, and see their final score when the quiz is completed.

---

## 🚀 Features

- 🧠 Multiple-choice quiz questions
- ✅ Select the correct answer
- ❌ Automatically identifies incorrect answers
- 🟢 Correct answer is highlighted in green
- 🔴 Wrong answer is highlighted in red
- 🔒 Once an answer is selected, it cannot be changed or selected again
- ➡️ Next button to move through the questions
- 📊 Displays the final score after completing the quiz
- 📱 Responsive and clean user interface
- ⚡ Built using vanilla JavaScript without external libraries

---

## 🛠️ Technologies Used

- HTML5 – Structure of the quiz
- CSS3 – Styling and responsive layout
- JavaScript – Quiz logic, answer checking, question navigation, and score calculation

## 🎮 How It Works

1. The quiz displays a question with multiple answer options.
2. The user selects one answer.
3. The selected answer cannot be changed or selected again.
4. If the answer is correct:
5. The selected answer becomes green.
6. The score is increased.
7. If the answer is incorrect:
8. The selected answer becomes red.
9. The correct answer automatically becomes green.
10. The user clicks the Next button to continue.
11. After the final question, the quiz displays the user's final score.
